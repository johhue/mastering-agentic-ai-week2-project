# Codex Build Log

This document summarizes the work completed with Codex to build the RemindMe customer support RAG application.

## What We Built

We created a Pinecone-backed customer support AI system for RemindMe. The application uses OpenAI embeddings and an OpenAI chat model to answer questions over support tickets, FAQs, and product manuals.

The system includes:

- Data ingestion into Pinecone
- Pinecone inspection utilities
- A Streamlit chatbot UI
- A command-line RAG question-answering utility
- A launcher script for the Streamlit app
- Confidence-based fallback behavior to avoid unsupported answers

## Data Sources

The application reads support data from the local `RemindMe*` directories:

- `RemindMe Company Data/`
- `RemindMe Company Manuals/`

These include:

- Help desk tickets
- Customer records
- Employee records
- Software variance data
- FAQs
- User guides
- Product documentation
- Compliance manuals
- HR policies
- Legal disclosures
- Help desk manuals

## Pinecone Upsert Script

We created `upsert_to_pinecone.py`.

This script:

- Loads secrets from `.env`
- Finds directories matching `RemindMe*`
- Reads supported text files such as `.json`, `.md`, `.txt`, `.yaml`, and `.csv`
- Splits file contents into overlapping chunks
- Creates OpenAI embeddings using `text-embedding-3-small`
- Uses `512` embedding dimensions by default to match the Pinecone index
- Upserts vectors into Pinecone with useful metadata:
  - `source`
  - `source_name`
  - `source_dir`
  - `chunk_index`
  - `text`
  - `sha256`

Verified dry run:

```bash
uv run python upsert_to_pinecone.py --dry-run
```

The dry run loaded `92` chunks from the RemindMe data and manuals.

## Streamlit Chatbot

We created `support_chatbot.py`.

This is the main customer support AI chatbot application. It uses Streamlit for the UI and combines keyword search with semantic search.

The chatbot:

- Loads `.env` secrets
- Builds a local keyword index over the RemindMe files
- Uses OpenAI embeddings to query Pinecone for semantic matches
- Merges keyword and semantic results into a hybrid retrieval score
- Sends retrieved context to an OpenAI LLM
- Shows retrieved sources and confidence signals
- Escalates to a human support specialist when confidence is too low

The fallback behavior is designed to reduce hallucinations. If retrieval does not find strong enough evidence, the assistant does not guess.

## Streamlit Launcher

We created `run_support_chatbot.sh`.

Run the chatbot with:

```bash
./run_support_chatbot.sh
```

By default, it launches Streamlit on port `8501`.

To use a different port:

```bash
STREAMLIT_PORT=8502 ./run_support_chatbot.sh
```

## Command-Line RAG Query Utility

We created `query_openai_pinecone.py`.

This command-line utility lets a user ask a question and receive an answer generated by OpenAI using Pinecone RAG context.

Example:

```bash
uv run python query_openai_pinecone.py "How do I create a reminder?" --show-sources
```

It:

- Loads `.env`
- Requires a question, either as command-line text or interactive input
- Embeds the question with OpenAI
- Queries Pinecone
- Builds RAG context from retrieved chunks
- Calls the OpenAI chat model
- Prints the answer
- Optionally prints retrieved sources

By default, hallucinations are not permitted. If retrieval confidence is too low, the utility escalates instead of answering.

To permit less-grounded answers:

```bash
uv run python query_openai_pinecone.py "What should I do if reminders fail?" --allow-hallucinations
```

When `--allow-hallucinations` is used, the model may answer beyond the retrieved context, but it is instructed to clearly state when an answer is not supported by the retrieved sources.

## Final Application Flow

1. Run `upsert_to_pinecone.py` to embed and upload RemindMe data into Pinecone.
2. Use `query_pinecone.py` to confirm the expected files are present.
3. Launch `support_chatbot.py` with `run_support_chatbot.sh` for the Streamlit chatbot.
4. Use `query_openai_pinecone.py` for terminal-based RAG questions.
5. Let the confidence fallback escalate uncertain answers rather than hallucinating.
